# SPRINT 04 — ADAPTIVE INTELLIGENCE

## Goal
Make answers change the interview meaningfully.

## Implement

- vagueness detection
- claim extraction

- continuous challenge vector

Every answer can update:
- competency belief
- confidence
- challenge dimensions
- open gaps

2. state updates
3. customer-impact gap appears
4. Product selected
5. targeted metric probe
