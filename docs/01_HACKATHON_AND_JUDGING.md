# 01 — HACKATHON CONTEXT & JUDGING

## Competition objective

PS-11 asks for an adaptive voice interview panel with one or more AI interviewers representing roles such as Technical, Hiring Manager, Customer, Product Manager and Behavioural Interviewer. The interview must adapt based on prior answers rather than following a fixed list.

## Mandatory proof

- Real-time and interruptible voice
- Multiple roles/personas
- Shared candidate context
- Dynamic follow-up questions
- Controlled turn-taking
- Role-play/scenario questions
- Difficulty adaptation
- Vague/contradictory answer handling
- Transcript-linked evidence
- Structured final assessment
- Clear AI disclosure

## Judging strategy

Innovation:
- Shared candidate intelligence, not merely multiple personas.
- Continuous uncertainty reduction.
- Cross-role reasoning.

Agora:
- Use Agora as the real-time voice execution plane.
- Prove interruption, session control, state/events and meaningful runtime context.
- Use official capabilities rather than superficial branding.

Technical:
- Explicit state model.
- Deterministic orchestration.
- Typed event contracts.
- Replayable interview trajectory.
- Reliable multimodal transitions.

Voice/conversation:
- Low perceived latency.
- Clean turn-taking.
- Natural role transitions.
- Candidate can interrupt, clarify, disagree, or say “I don't know.”

Impact:
- Human-readable hiring evidence.
- Useful candidate feedback.
- Real-world task simulation.

Product:
- Job setup → interview → evidence → assessment.
- Configurable roles/rubrics without rewriting core code.

Demo:
- Show one answer materially changing the next action.
- Make the reason for adaptation visible to judges.
- Show a Technical → Product transition and at least one interruption.
