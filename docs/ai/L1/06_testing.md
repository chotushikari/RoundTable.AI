# Testing

Run `npm test`, `npm run lint`, `npm run typecheck`, `npm run verify:api`, and `npm run build`. `npm run verify` additionally requires a complete `.env.local` through `doctor`.

Assessment tests exercise oversized multilingual history, byte ceilings including the wire schema, invalid evidence IDs, and preservation of full ratings/evidence. Provider tests simulate cooldown across JSON/speech calls and retry-window expiry without network access. The separate optional provider smoke script checks one real request with synthetic evidence.

Offline demo regression runs five answers through durable state with pause/repeat, simultaneous duplicate requests, fragmented introductions/technical/behavioural answers, and unheard questions for every role. It verifies all-role analysis, prevents premature closing, and checks Product prompt adaptation. The live gate requires real Agora join/RTC/RTM/renewal proof, five-role completion after the closing audio, five-minute maximum, pause/repeat/readiness checks, 20 barge-in attempts with p95 stop time, impaired-network recovery, SSE/audio latency, deployed Supabase RLS tests, and E2B isolation checks. Allow roughly 30 seconds per answer and record actual timing. Verify question receipts after a full question, after interruption/repeat, and after reconnect; partial phrases must not skip Product or Customer. Offline success must not be represented as live success.
