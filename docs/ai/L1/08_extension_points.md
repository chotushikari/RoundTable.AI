# Extension Points

Add role policy through `PanelRole`, plan objectives, evaluator schema, and controller rules together. Add candidate-callable tools through the shared tool union, explicit command boundary, confirmation policy for writes, audit record, report projection, and tests. Add modalities by updating public types, session state, candidate polling, and workspace rendering.

Video identity/lip-sync, avatars, ATS integration, multilingual speech, human takeover, and candidate accounts are later opt-in features. Biometric inference must never produce an automatic rejection.
